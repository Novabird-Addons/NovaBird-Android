# NovaBird Mail artwork

Source files of the NovaBird Mail logo (viewBox 96 × 96, NovaBird blue `#2F6BD8`, same as the NovaBird add-ons).

| File | Use |
|---|---|
| `novabird-mail-logo.svg` | Main logo: swallow with envelope. App logo, launcher icon, Compose screens. |
| `novabird-mail-logo-swallow.svg` | Logo without envelope, for small sizes. |
| `novabird-swallow-mono.svg` | Swallow only, one color, transparent. Monochrome launcher icon and notification icon (24 dp). |

The Android vector drawables in `app-novabird/src/main/res/drawable` and
`src/commonMain/composeResources/drawable` are converted by hand from these files. Keep them in sync.
